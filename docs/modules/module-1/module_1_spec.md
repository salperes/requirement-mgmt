# Module-1 Spec — Requirement CRUD + Versioning + Baseline

## Goal
Deliver the RMS core: manual requirements + version history + baselines.

## In Scope
- Requirement CRUD (soft delete)
- Requirement versions (snapshot_json per change)
- Baseline creation (freezes versions)
- Search/filter + pagination
- Baseline export (MD/CSV)

## Out of Scope
- Links/RTM UI (Module-3)
- Verification/Evidence (Module-4)
- Workflow collaboration (Module-2)
- Import (Module-5)
- Compliance (Module-6)
