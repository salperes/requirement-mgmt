# Parsing Rules (Module-5)

## Clause Detection (Deterministic)
- Numbered clauses (1., 1.1, 1.1.1)
- Bullet points (-, •)
- Table rows (for XLSX)

## AI Assistance (Optional, Non-binding)
- Suggest clause boundaries
- Suggest discipline/type
- Must be confirmed by user

## Constraints
- Parsing must be reproducible
- Original text must be preserved verbatim
