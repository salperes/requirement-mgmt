# RMS Agent Implementation Pack (Module-0 + Module-1)

This pack contains the complete set of Markdown specifications needed for AI agents to implement the RMS project incrementally (Module-0 and Module-1).

## What’s inside
- Project goals, scope and non-scope
- Repository structure and conventions
- Domain model + business rules
- RBAC + permissions matrix
- API contract + error format
- Database schema + migrations plan
- UI screens (MVP)
- Acceptance tests (BDD) + QA checklist
- Seed data
- Agent task prompts (Architect/Backend/Frontend/QA)

## Modules covered
- **Module-0:** Project skeleton + Auth + RBAC + Audit + DB migrations
- **Module-1:** Requirement CRUD + Versioning + Baseline (core RMS)

> Source of truth: The documents in this folder. If something is missing, add an ADR under `docs/adr/`.
