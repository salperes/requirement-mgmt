# UI MVP Screens (Module-0 + Module-1)

## Module-0
### Login
- Email + password
- Error on invalid credentials

### Me
- Show current user + role badges

### Admin Users (Admin only)
- List users
- Create user
- Assign roles

## Module-1
### Requirements List
- Search: req_code/text
- Filters: discipline, type, status
- Toggle include_deleted
- Link to details

### Requirement Detail
- Editable fields: title, text, discipline, type, is_explanation, status
- Save with optional change_reason
- Versions tab: list versions + view snapshot

### Baselines
- Create baseline from filter selection
- List baselines
- Baseline detail: items list
- Export baseline: MD/CSV
